tabby-keepass-ssh documentation
================================

`tabby-keepass-ssh <https://github.com/search5/tabby-ssh-keepass>`_ is a
`Tabby <https://tabby.sh>`_ plugin that automatically fills SSH passwords and
TOTP codes from a KeePass database during keyboard-interactive authentication
— no manual copy-paste required. See :doc:`integration` for how it works
together with Tabby's built-in SSH connections.
